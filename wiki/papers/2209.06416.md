# ImageArg: A Multi-modal Tweet Dataset for Image Persuasiveness Mining

> タグ: #argument-mining #multimodal #dataset #persuasion #social-media #twitter
> 著者: Liu, Guo, Dai & Litman
> 年: 2022
> ソース: arXiv:2209.06416 (cs.CL)
> raw: [[raw/papers/2209.06416.pdf]]

## 一行要約

Twitterの画像付きツイートにおける画像の説得力をマイニングする多次元アノテーションデータセットImageArgを構築。

## アノテーション次元

| 次元 | 内容 |
|------|------|
| Stance | 支持/反対/中立 |
| Image Persuasiveness | 画像追加による説得力向上スコア（0〜4） |
| Image Content Type | Statistics / Testimony / Anecdote / Slogan / Scene photo / Symbolic photo |
| Persuasion Mode | Logos（論理）/ Pathos（感情）/ Ethos（信頼性） |

## データセット統計（gun controlトピック）

- 1,003サンプル（Stance付き）
- コンテンツタイプ: Symbolic photo 23.4%、Scene photo 21.9%、Anecdote 19.8%など
- 説得モード: Pathos 50.6%、Logos 37.9%、Ethos 11.6%

## モデル

ResNet50（画像）+ BERT（テキスト）のマルチモーダル融合 → 線形分類器

## 主な発見

- 対立スタンスで画像コンテンツタイプが異なる（支持側はScene/Statistics、反対側はSymbolic/Anecdote多い）
- アノテーター間一致率: Stance(α=76.1)は高く、Persuasion Mode(Logos:55.3, Pathos:51.0, Ethos:57.8)は低い

## 我々の研究への示唆

議論支援においてマルチモーダル議論の分析（画像+テキスト）は今後の重要領域。特に**Logos/Pathos/Ethos**の説得モード分類は議論品質評価・フィードバック設計に直接使える分類体系。ソーシャルメディアにおける議論の視覚的側面を考慮するきっかけに。
