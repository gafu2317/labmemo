# ConQRet: Benchmarking Fine-Grained Evaluation of Retrieval Augmented Argumentation with LLM Judges

> タグ: #argument-mining #rag #evaluation #llm-judge #benchmark
> 著者: Dhole, Shu & Agichtein (Emory University)
> 年: 2024
> ソース: arXiv:2412.05206 (cs.CL)
> raw: [[raw/papers/2412.05206.pdf]]

## 一行要約

Retrieval Augmented Argumentation（RAArg）の細粒度評価のために複数LLM Judgeを設計し、ProCon.orgから構築したConQRetベンチマークで検証。

## 問題設定

- 論争的トピック（中絶・ワクチン接種など）の議論生成をRAG設定で行うRAArg
- 長文・複雑な議論の自動評価は人手アノテーションが困難
- 既存の単一スコアメトリクスは解釈性・細粒度評価に不十分

## LLM Judgeの評価次元

| 次元 | 説明 |
|------|------|
| Context Relevance | 検索された証拠文書の関連性（文書単位で評価） |
| Argument Groundedness | 生成議論が証拠に基づいているか |
| Argument Quality | 論理的一貫性・説得力・適切さ（15次元） |

- **Listwise+RAG Fine-Grained**: 上記3指標を一度のプロンプトで一括評価
- Self-Consistency（複数順序での平均）でさらに精度向上

## ConQRetベンチマーク

- ProCon.orgからの人手記述議論（長文・証拠付き）
- 98トピック、6,500証拠文書
- Train/Test: 68/30トピック（トピック・文書の重複なし）

## RAArg参照実装

```
BM25 + LLM Reranking（スタンス特化）
    ↓
Evidence-Augmented Argument Generation（GPT-4o-mini, few-shot）
    ↓
LLM Judge（Listwise+RAG Fine-Grained）で評価
```

## 実験結果

- LLM Judge（Listwise+SC, GPT-4o）は人間専門家との合意でCrowdソーシングを上回る
- Listwise+RAG Fine-Grainedは無関連文書の増加に対してPrecisionが単調に低下（敏感）
- Direct（TruEra）メトリクスは無関連文書への感度が不十分
- GPT-4oはGeminiより一貫した評価を示す

## 我々の研究への示唆

議論支援システムでのLLMによる**議論品質の自動評価**設計に直接応用可能。細粒度LLM Judge（文書単位のContext Relevance + Groundedness + Quality）を一括評価するListwiseプロンプトは、議論支援フィードバックの自動化に使える。RAArg設定（証拠検索→議論生成→評価）は議論支援パイプラインの参考になる。
