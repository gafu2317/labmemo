# Dynamic Knowledge Integration for Counter-Argument Generation with Web Search

> タグ: #counter-argument #argument-mining #rag #llm #evaluation #dataset
> 著者: (CANDELA dataset paper)
> 年: 2025
> ソース: arXiv:2503.05328
> raw: [[raw/papers/2503.05328.pdf]]

## 一行要約

Webサーチで動的に取得した外部知識をLLMに組み込んで反論を生成するRAGパイプラインを提案し、LLM審判評価でρ=0.82の高相関を確認。

## 問題設定

- LLMの反論生成は学習データの知識に限定され、事実的根拠が弱い
- 外部知識（Web情報）を動的に統合することで事実性・説得力を向上させたい
- CANDELAデータセット（150ペア）を新規構築して評価基盤を整備

## データセット: CANDELA

- **150件**の議論-反論ペア
- 多様なトピック（政治・社会・科学）
- 人手でアノテーションされた品質スコア

## 手法

### RAGパイプライン

```
入力議論 → キークレーム抽出 → Webサーチクエリ生成
→ 検索結果取得 → 関連スニペット選択
→ LLM（外部知識を付加して反論生成）
```

### 実験モデル

| モデル | パラメータ |
|--------|---------|
| Command R+ | 104B |
| Mistral-7B | 7B |
| Claude 3.5 Sonnet | — |

## 評価: LLM-as-Judge

- Claude 3.5 Sonnetを審判として品質評価
- 人手評価との相関: **Spearman ρ = 0.82**
- 評価軸: 事実性・説得力・関連性・流暢性

## 主な結果

- 外部知識統合により事実性・説得力が有意に向上
- 大規模モデル（Command R+）は小規模モデルを上回る
- LLM審判は人手評価の代替として十分な信頼性を示す

## 我々の研究への示唆

議論支援システムでの**事実根拠付き反論生成**に直接応用可能。Web検索を動的に組み込むRAGアプローチは、リアルタイムの議論支援でも機能しうる。またLLM審判（ρ=0.82）の高い信頼性は、システム評価設計における自動評価の根拠となる。
