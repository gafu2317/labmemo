# Def-DTS: Deductive Reasoning for Open-domain Dialogue Topic Segmentation

> タグ: #topic-shift #dialogue #llm #deductive-reasoning #prompting
> 著者: Lee, Yoo, Jung & Song (Yonsei University / LOTTE / LG / Onoma AI)
> 年: 2025
> ソース: ACL 2025 Findings (arXiv:2505.21033)
> raw: [[raw/papers/2505.21033.pdf]]

## 一行要約

LLMの多段階演繹推論（文脈抽出→発話意図分類→話題転換判定）でオープンドメイン対話トピックセグメンテーションを解く、Def-DTSを提案。

## 問題設定

**Dialogue Topic Segmentation (DTS)**：対話を一貫したトピック単位に分割するタスク。
- データ不足・ラベル曖昧性・増大する複雑性が課題
- LLMの推論能力がDTSに未活用だった

## 手法：Def-DTS（3ステップ演繹）

```
① 双方向文脈抽出（前2発話・後3発話のサマリ）
② 発話意図分類（5クラス: JUST_COMMENT / JUST_ANSWER / DEVELOP_TOPIC / INTRODUCE_TOPIC / CHANGE_TOPIC）
③ 演繹的話題転換判定（意図→YES/NOに変換）
```

### 意図クラスの話題転換対応

| 意図 | 話題転換 |
|------|---------|
| JUST_COMMENT / JUST_ANSWER / DEVELOP_TOPIC | NO |
| INTRODUCE_TOPIC / CHANGE_TOPIC | YES |

- XML構造化プロンプトを採用（NL < JSON < XML の性能順）
- ドメイン非依存な汎用意図リストを設計

## 実験結果

3データセット（TIAGE / SuperDialseg / Dialseg711）で評価：

| データセット | Def-DTS Pk↓ | 比較最良 |
|------------|------------|--------|
| TIAGE | **0.232** | RoBERTa 0.265 |
| SuperDialseg | **0.315** | DialSTART 0.373 |
| Dialseg711 | **0.015** | DialSTART 0.179 |

全データセットでSOTA（LLMベース・教師あり含む）を上回る

## 自動ラベリングの可能性

GPT-4によるラベリングのCohen's Kappa：
- TIAGE: 0.485（人間アノテーター間0.479を超える）
- Dialseg711: 0.975（ほぼ完全一致）

## 我々の研究への示唆

演繹的推論によるDTSは議論支援における**リアルタイム話題管理**に直接応用可能。特に5クラス意図分類（DEVELOP/INTRODUCE/CHANGE）は議論の「展開・新争点導入・脱線」の区別に使える。XML構造化プロンプトとLLM自動ラベリングは、議論支援システムのデータ収集コスト削減にも有用。
