# PDSQI-9: Provider Documentation Summarization Quality Instrument for LLMs

> タグ: #medical-summarization #evaluation #quality-instrument #clinical-nlp
> 著者: Moen, Schloss, Chiang et al. (University of Wisconsin-Madison + Epic Systems + UW Health)
> 年: 2025
> ソース: arXiv:2501.08977 (cs.CL)
> raw: [[raw/papers/2501.08977.pdf]]

## 一行要約

LLM生成臨床文書要約の品質を測定する9属性Likertスケール評価器具PDSQI-9を開発・検証し、ICC=0.867の高い評価者間信頼性を確認。

## 問題設定

- 電子カルテへのLLM適用が進むが、臨床文書要約の品質評価基準が未整備
- 医療ドメイン特有の品質要件（正確性・倫理的表現・有用性）を体系化する必要

## PDSQI-9の9属性

| 属性 | 説明 |
|------|------|
| Accurate | 情報が正確か |
| Cited | 出典が明示されているか |
| Comprehensible | 理解しやすいか |
| Organized | 構造的に整理されているか |
| Succinct | 簡潔か |
| Stigmatizing | 差別的表現がないか |
| Synthesized | 複数ソースを統合できているか |
| Thorough | 網羅的か |
| Useful | 臨床的に有用か |

## 信頼性検証

- ICC（級内相関係数） = 0.867（高い評価者間信頼性）
- Cronbach's α = 0.879（高い内的一貫性）
- 4因子モデルで属性を整理

## 我々の研究への示唆

直接的な関連度は低い（医療ドメイン特化）。ただし多属性評価スケールの設計手法（信頼性検証・因子分析）は議論支援システムの評価器具設計の参考になる。
