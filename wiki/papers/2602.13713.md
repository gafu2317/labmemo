# On Theoretically-Driven LLM Agents for Multi-Dimensional Discourse Analysis

> タグ: #argument-mining #multi-agent #rag #rephrase #argumentation-theory
> 著者: Uberna, Wawer, Chudziak & Koszowy (Warsaw University of Technology)
> 年: 2026
> ソース: arXiv:2602.13713 (cs.CL)
> raw: [[raw/papers/2602.13713.pdf]]

## 一行要約

論証理論をRAGで組み込んだ4エージェントMASが議論ディスコースでの言い換え（rephrase）分類において、zero-shotベースラインを大幅に上回ることを示す。

## 問題設定

- 議論的ディスコースにおける言い換え（改訂・言い直し）の機能的分類は重要だが計算論的には困難
- LLMは表面的類似度は検出できるが言い換えの修辞機能（強調/弱体化/一般化など）を捉えられない
- 論証理論の明示的な知識をエージェントに組み込む効果を検証

## 言い換えカテゴリ（D-I-S-G-O）

| カテゴリ | 説明 | 例 |
|---------|------|-----|
| De-intensification | 主張の強度を弱める | "terrible" → "unfortunate oversight" |
| Intensification | 主張の強度を強める | "doing great" → "killing it" |
| Specification | 詳細化・範囲を絞る | - |
| Generalisation | 抽象化・範囲を広げる | "not answering" → "never answer" |
| Other | 上記に当てはまらない | - |

## マルチエージェントアーキテクチャ

- **Informed System**: 4エージェント（Asserting/Arguing/Disagreeing/Broker Critic Agent）に論証理論をRAGで提供
- **Zero-Shot System**: 同一アーキテクチャだが理論知識なし
- RAG知識ベース: Inference Anchoring Theory, 言い換えタクソノミー（Kiljan & Koszowy 2024）

データ: US2016大統領討論トランスクリプト、401言い換えペア

## 実験結果

| システム | Macro F1 | MCC |
|---------|----------|-----|
| Single Agent, 0-Shot | 0.27 | 0.16 |
| Single Agent + RAG | 0.54 | 0.48 |
| MAS 0-Shot | 0.38 | 0.24 |
| **MAS + RAG** | **0.67** | **0.64** |

- RAG単体の効果（+0.27）とMAS単体の効果（+0.11）が相乗的に作用
- GeneralisationカテゴリでMAS+RAGが最大の改善（0.33→0.81）

## 我々の研究への示唆

議論支援システムでの**言い換え・改訂の機能検出**に直接応用可能。Informed MAS（理論知識をRAGで参照するエージェント群）のアーキテクチャは、議論中の修辞戦略を自動分析するツールとして参考になる。誘導・操作的言い換えの検出はオンライン議論の品質管理にも活用できる。
