# PAKT: Perspectivized Argumentation Knowledge Graph for Deliberation Analysis

> タグ: #argumentation-framework #argument-mining #knowledge-grounded #debate #dataset #visualization
> 著者: (Heidelberg University + Bielefeld University)
> 年: 2024
> ソース: arXiv:2404.10570
> raw: [[raw/papers/2404.10570.pdf]]

## 一行要約

debate.orgの140議題・24,646件の議論からPAKT知識グラフを構築し、MediaFrames・Schwartzバリュー・ConceptNetを統合してNeo4jで討論分析を実現。

## 問題設定

- 討論（deliberation）の分析には議論の立場・価値観・概念を統合した知識表現が必要
- 既存の議論データセットは構造化が不十分で多角的分析に対応できない
- 異なる視点（パースペクティブ）の関係性を可視化・分析する基盤が欠如

## データセット: debate.org

- **140議題**（トピック）
- **24,646件**の議論
- 賛否2立場、複数ユーザーによる構造化討論

## PAKTフレームワーク

### 知識統合レイヤー

| レイヤー | 内容 |
|---------|------|
| **MediaFrames** | メディアフレーミング分析（政治・経済・道徳等の枠組み） |
| **Schwartz Values** | 10種の普遍的価値観（達成・安全・権力・博愛等） |
| **ConceptNet** | 常識知識グラフ（概念間関係） |

### グラフ構造（Neo4j）

```
議題 → 議論 → クレーム → 概念ノード
                ↓
        フレーム/価値観ラベル
```

## 討論分析機能

- **フレーム分析**: 賛否でどのフレームが多用されるか可視化
- **価値観対立検出**: 議論で衝突する価値観の特定
- **概念ネットワーク**: 関連概念の知識グラフ探索

## 我々の研究への示唆

議論支援システムにおける**議論の構造化・可視化**に応用可能。特に「なぜ意見が対立するか（価値観・フレームの違い）」を明示化するアプローチは、議論の深い理解支援に直接役立つ。Neo4jグラフDBの活用は議論構造の永続化・検索設計の参考になる。
