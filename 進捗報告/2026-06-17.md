## 研究概要
逆さま不動産（空き家マッチングサービス）では、物件を貸したい大家ではなく借り手が自分の活動や想いを大家にアピールする必要がある。しかし、こうした交渉的な対話は借り手にとってコストが高く、慣れない利用者には難しい。
そこで本研究では、借り手の熱意を代弁して大家にアピールする交渉対話エージェントを試作する。借り手の情報（目的・希望条件・確認したい質問）を構造化プロファイルとして入力し、LLMエージェントが大家との対話を自動生成する。感情表現の指示の有無が対話品質に与える効果を比較実験により評価する。


## 1. 前回の進捗・課題

- 評価が難しい（「大家が貸したいと思わせる」を直接測定できない）
- 実験条件の統制が不十分

## 2. 進捗

評価指標の設計・実験条件の統制・動作確認

### 作業1
評価指標の設計

最終成果指標が「大家が貸したいと思わせること」であり直接測定が困難なため、以下の評価項目を設定した。

| 項目 | 聞き方 | 尺度 |
|------|--------|------|
| 根拠忠実性 | 記事にないことを言っていないか | 違反件数 |
| 熱意の伝達 | 借り手の想いが伝わったか | 1〜5 |
| 人となり | どんな人かわかったか | 1〜5 |
| 使い方のイメージ | この物件をどう使うか想像できたか | 1〜5 |
| 貸したいと思うか | あなたが大家なら、この人と次の話（内見・詳細相談）に進みたいと思うか | 1〜5 |

### 作業2
実験条件の統制

BaselineとProposedの差異をRealizer（発話生成）のみに限定し、PlannerとVerifierは共通化した。

```
              【Baseline】                    【Proposed】
                   |                               |
         [共通 Planner] ←──── 同じJSON ────→ [共通 Planner]
                   |                               |
     [Neutral Realizer]               [Emotional Realizer]
                   |                               |
         [共通 Verifier] ←──── 同じ基準 ──→ [共通 Verifier]
                   |                               |
              発話（中立）                    発話（感情あり）
```

また、ターン数を短めに調整した。
