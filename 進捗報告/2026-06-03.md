### 作業2: 実験システムの実装

#### 実施内容・結果
- 借り手AI（Baseline / Structured）、大家AI、多ターン対話ループを実装
- 物件YAMLと借り手YAMLを分離し、1つの物件に複数の借り手がアピールする1対多の構図に変更
- ランダムにN人の借り手を選んで実験を実行できるCLIを整備

```bash
python scripts/run_experiment.py \
  --property property01_kuwana \
  --random-cases --n 5 \
  --conditions baseline,structured
```

#### 課題・問題点（あれば）
- 物件YAMLは現在1件（桑名の古民家）のみ。複数物件への拡張が今後必要


### 作業3: 借り手ケースYAMLの整備

#### 実施内容・結果
- 449件のMarkdownファイルをLLM（claude-haiku-4-5）で一括変換し、YAMLケースファイルを生成
- article・profile（目的・希望・制約・質問）・slotsを自動生成
- MDとYAMLをフォルダ分離（cases_raw/ と cases/）

#### 課題・問題点（あれば）
- LLMが生成したprofileは未検証。実験に使うケースは人手で確認が必要


### 作業4: 対話ログビューアの実装

#### 実施内容・結果
- Flask製のLINE風チャットUIを実装
- 左：スクロール可能な吹き出し形式の対話表示
- 右：Slotsチェックリスト（ブラウザ上でチェック・ターン番号入力・JSON保存）

### 作業5: 評価基準書（rubric.md）の作成

#### 実施内容・結果
- `eval/rubric.md` を作成
- 4評価軸の判定基準・具体例を記載

| 評価軸 | 測定方法 |
