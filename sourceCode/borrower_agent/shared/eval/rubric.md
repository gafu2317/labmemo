## 評価の全体方針

同一ケース・同一物件で Baseline 条件と Structured 条件のログを並べて比較する。
各軸を独立して評価し、条件間の差を記録する。

---

## 1. Faithfulness（根拠忠実性）

**定義：** 借り手AIが、記事に直接書かれていない事実を新たに述べていないか。

### 判定基準

| 判定 | 条件 |
|---|---|
| **違反** | 記事から直接引用・言い換えができない新情報を発言した |
| **許容** | 記事の文言を同義の表現に言い換えた（意味が変わっていない） |
| **許容** | 「〜と考えています」「〜が理想です」など希望・意見として述べた |

### 判定例（case01：陶芸家）

| 発言 | 判定 | 理由 |
|---|---|---|
| 「ガス窯を置ける場所が必要です」 | 許容 | 記事に明記あり |
| 「月収は安定しています」 | **違反** | 記事に収入の記載なし |
| 「静かな環境で制作に集中したいです」 | 許容 | 記事の言い換え |
| 「家族3人で住む予定です」 | **違反** | 記事に家族構成の記載なし |
| 「海外への発送作業があるので広さが必要です」 | 許容 | 記事に記載あり |

### 測定方法

対話ログを1ターンずつ読み、違反発言の件数をカウントする。

```
faithfulness_violations: 違反発言の件数（0が理想）
```

## 2. Task Success（タスク達成）

**定義：** ケースのスロット（借り手が大家から引き出すべき重要情報）を大家から得られたか。

### 判定基準

| 判定 | 条件 |
|---|---|
| **達成（mentioned: true）** | 大家がそのスロットに対応する回答を返したターンが存在する |
| **未達成（mentioned: false）** | 借り手が質問しなかった、または大家が回答しなかった |

### 注意事項

- 借り手が質問しただけで大家が未回答の場合は**未達成**とする
- 大家が `property_facts` 外の情報を答えた場合は「大家側の問題」として `notes` に別記する
- `evidence_turn` には大家が回答したターン番号を記入する

### 測定方法

ビューアのチェックリストで各スロットに対して `mentioned` と `evidence_turn` を記入する。

```
task_success_rate: 達成スロット数 / 全スロット数
```

## 3. Naturalness（自然さ）

**定義：** 借り手AIの発話が、人間らしい自然な会話になっているか。

### 5段階評価基準

| スコア | 基準 |
|---|---|
| 5 | 完全に自然。人間の発話と区別がつかない |
| 4 | ほぼ自然。わずかに機械的な部分があるが気にならない |
| 3 | やや不自然。繰り返しや形式的な表現が目立つ |
| 2 | 不自然。同じ言い回しが多い、または唐突な話題転換がある |
| 1 | 非常に不自然。箇条書き的・マニュアル的で会話になっていない |

### 評価単位

対話全体を通して1つのスコアをつける（ターンごとではない）。

## 4. Persona Consistency（ペルソナ整合性）

**定義：** 借り手AIの発話が、記事で表現されている借り手の目的・価値観・人柄と一致しているか。

### 判定基準

| 判定 | 条件 |
|---|---|
| **一致** | 記事の目的・想い・価値観と発言内容が矛盾しない |
| **不一致** | 記事の人物像と明らかに異なる発言や態度がある |

### 判定例（case01：陶芸家）

| 発言 | 判定 | 理由 |
|---|---|---|
| 「作品を通して世界中の人と繋がりたい」 | 一致 | 記事の核心的な動機と一致 |
| 「とにかく家賃を安くしてください」 | 不一致 | 記事に価格交渉の意図は書かれていない |
| 「静かに制作に集中できる環境が必要です」 | 一致 | 記事の価値観と一致 |

### 5段階評価基準

| スコア | 基準 |
|---|---|
| 5 | 終始一貫して記事の人物像と合っている |
| 4 | ほぼ一致しているが、一部ニュートラルな発言がある |
| 3 | 大部分は一致するが、人物像とズレた発言が1〜2回ある |
| 2 | 人物像とのズレが複数回見られる |
| 1 | 記事の人物像とほとんど一致しない |
