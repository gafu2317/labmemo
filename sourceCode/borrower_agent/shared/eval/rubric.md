## 評価の全体方針

同一ケース・同一物件で Baseline 条件と Proposed 条件のログをペアにし、条件名を隠して比較する。評価対象は借り手の発話のみとし、大家の返答は対話文脈として参照するが採点しない。

主指標は Perceived Passion（知覚熱意）と Meeting Intention（本人と話したい意向）。Faithfulness、Preparedness、Authenticity、Naturalnessを分離して測り、熱意と信頼性を混同しない。

## 0. 主指標

各項目を1（全くそう思わない）〜7（非常にそう思う）で評価する。

### Perceived Passion（知覚熱意）

- この活動は借り手本人にとって重要だと感じる
- 借り手はこの活動に強い思い入れを持っていると感じる
- 借り手は今後も粘り強く活動を続けそうだ

### Meeting Intention（面談意向）

- この借り手本人から、さらに詳しく話を聞いてみたい
- この借り手を、物件を貸す候補として検討したい

貸与の即時決定ではなく「対面で詳しく話すきっかけ」が対話目的であるため、Meeting Intentionを主要な成果指標とする。

### 分離して測る補助尺度

- **Enacted Commitment**：口先だけでなく、すでに行動していることが伝わった
- **Authenticity**：本人固有の、誇張の少ない語りに感じた
- **Preparedness**：物件の使い方を現実的に考えていると感じた
- **Perceived Risk**：貸した後の運用に不安を感じた（逆転項目ではなく独立に扱う）

## 1. Faithfulness（根拠忠実性）

**定義：** 借り手AIが、記事に直接書かれていない事実を新たに述べていないか。

### 判定基準

| 判定 | 条件 |
|---|---|
| **違反** | 記事から直接引用・言い換えができない新情報を発言した |
| **違反** | 記事に別々にある事実を、記事にない理由・目的・配慮で結びつけた |
| **許容** | 記事の文言を同義の表現に言い換えた（意味が変わっていない） |
| **許容** | 「〜と考えています」「〜が理想です」など希望・意見として述べた |

### 判定例（case01：陶芸家）

| 発言 | 判定 | 理由 |
|---|---|---|
| 「ガス窯を置ける場所が必要です」 | 許容 | 記事に明記あり |
| 「月収は安定しています」 | **違反** | 記事に収入の記載なし |
| 「静かな環境で制作に集中したいです」 | 許容 | 記事の言い換え |
| 「家族3人で住む予定です」 | **違反** | 記事に家族構成の記載なし |
| 「海外への発送作業があるので広さが必要です」 | 許容 | 記事に記載あり |

### 測定方法

対話ログを1ターンずつ読み、違反発言の件数をカウントする。

```
faithfulness_violations: 違反発言の件数（0が理想）
```

## 2. Task Success（使用イメージの伝達・補助指標）

**定義：** 借り手がその物件で何をしたいのか、大家が具体的にイメージできる発話になっているか。物件情報を網羅的に聞き出すことは目的としない。

### 判定基準

| スコア | 基準 |
|---|---|
| 5 | 活動内容、空間の使い方、その背景にある想いが具体的に想像できる |
| 4 | 使い方は十分に伝わるが、一部が抽象的である |
| 3 | 活動の概要は分かるが、物件での具体的な姿を想像しにくい |
| 2 | 希望設備や条件の説明が中心で、使い方がほとんど伝わらない |
| 1 | 何をしたい借り手なのか判断できない |

### 注意事項

- 設備名や広さの羅列だけでは高く評価しない
- 質問をする場合は、なぜ必要かという使用イメージが伴っているかを見る
- 大家が記事を知っていることを前提にせず、借り手自身の発話だけで伝わるかを判断する

### 測定方法

対話全体に対して1〜5のスコアを1つ付け、判断根拠となった借り手発話を記録する。

```
task_success: 1〜5（5が理想）
```

## 3. Naturalness（自然さ）

**定義：** 借り手AIの発話が、人間らしい自然な会話になっているか。

### 5段階評価基準

| スコア | 基準 |
|---|---|
| 5 | 完全に自然。人間の発話と区別がつかない |
| 4 | ほぼ自然。わずかに機械的な部分があるが気にならない |
| 3 | やや不自然。繰り返しや形式的な表現が目立つ |
| 2 | 不自然。同じ言い回しが多い、または唐突な話題転換がある |
| 1 | 非常に不自然。箇条書き的・マニュアル的で会話になっていない |

### 評価単位

対話全体を通して1つのスコアをつける（ターンごとではない）。

## 4. Persona Consistency（ペルソナ整合性）

**定義：** 借り手AIの発話が、記事で表現されている借り手の目的・価値観・人柄と一致しているか。

### 判定基準

| 判定 | 条件 |
|---|---|
| **一致** | 記事の目的・想い・価値観と発言内容が矛盾しない |
| **不一致** | 記事の人物像と明らかに異なる発言や態度がある |

### 判定例（case01：陶芸家）

| 発言 | 判定 | 理由 |
|---|---|---|
| 「作品を通して世界中の人と繋がりたい」 | 一致 | 記事の核心的な動機と一致 |
| 「とにかく家賃を安くしてください」 | 不一致 | 記事に価格交渉の意図は書かれていない |
| 「静かに制作に集中できる環境が必要です」 | 一致 | 記事の価値観と一致 |

### 5段階評価基準

| スコア | 基準 |
|---|---|
| 5 | 終始一貫して記事の人物像と合っている |
| 4 | ほぼ一致しているが、一部ニュートラルな発言がある |
| 3 | 大部分は一致するが、人物像とズレた発言が1〜2回ある |
| 2 | 人物像とのズレが複数回見られる |
| 1 | 記事の人物像とほとんど一致しない |
