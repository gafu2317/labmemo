# ママたちのほっとできるスペースを岐阜市に。

## 石榑　明美

愛知県出身で岐阜市在住しております。
現在、子供が二人いて、ハンドメイドの販売とカルチャーセンター（まちの習い事教室）とか自宅で講師もしています。
20年以上前からハンドメイドは基本的に布を使ったものを作っています。
いろんな種類のものを作っていて最近教えてるのはリースなど基本的に布を使った雑貨を作っています。ジャンルを絞ってというよりかは、世界観を絞りながら作品を作っています。
世界観に触れれるような雑貨屋さんを作りたいと思っています。

## やりたいこと

地域のママたちが子育ての息抜きができるような、販売とワークショップスペース、キッズスペースを備えた雑貨店が開きたいです。
私自身、子どもが小さい頃、子ども同伴での雑貨店への入店やワークショップへの参加を断られた経験があります。何時間も子どもを託児施設などに預けなくても、ほんのひとときでも可愛いものを見たり作ったりすることで癒され、子育てを頑張る力になる事もあると思います。
また、私自身、コロナ禍の中、知らない土地に引っ越してきて地域のママと触れ合う機会もなく、孤独な子育てはこんなにも辛いのかと身をもって経験しました。
ママたちが知り合える、子育ての悩みを気軽に話せる、そんな交流の場にもなればと思っています。
