# 【就労継続支援B型】×【ITパソコン特化型】事業所を名古屋でOPENしたい！

**更新日:** 2022.04.12

## 真鍋 優

2021年の5月に 【就労継続支援B型】×【パソコン特化型】を地元一宮で設立する運びになりました。まだまだ日本の福祉は世界から比べると遅れていて、変化をしないといけないところが多いです。

## やりたいこと

就労継続⽀援B型の事業所を名古屋市内で作りたいです。
弊社は今、私の地元である一宮で【就労継続支援B型】×【ITパソコン特化型】事業所を
昨年の５月にオープンしました。すごく反響が大きく一宮の事業所が定員が満員になり、
また、名古屋で早くオープンしてほしいと支援員さんや利用者さんの親御さんからの声が多くこの度、さかさま不動産に掲載していただく運びになりました。
【弊社の特徴】
①：工賃がダントツで高い点になります。（最大時給1030円）
他の事業所さんが1ヶ月の平均工賃が1万5000円前後のところ、弊社は10万円を目指せる仕組みになっております。まだ開設して一年も経っていませんが7万円くらい稼げる利用者さんも出てきています。
②：パソコン特化型の事業所になるのでスキルが身につきB型事業所から一般就職を目指せるとこになります。
今、全国の福祉の課題として、なかなかB型事業所から就職ができない点が大問題になっています。その理由として、パンやクッキーを作ったり、部品や段ボールを組み立ててもなかなかその先の進路を見いだせないからです。弊社は、お仕事をしながらパソコンのスキルが身に付くようになっているため、事務仕事の一般就職も目指せるようになっています。
また、先月ですが１名一般就職の方を送り出せることができました。
③：仕事の種類が豊富なてんになります。
うちの事業所は、DM送信や、sns運用などのパソコンを触ったことがない人でもできるお仕事から、名刺やチラシのデザイン作成や画像編集などレベルに合わせたお仕事を準備させていただいております。

## やりたい理由

実は、自分もうつ病やパニック障害を患い半年ほど寝込んでいた時期があり、
もう一般就職はできないなと、不安の毎日が続きました。
その時に幼なじみの小島（代表取締役）が一緒に働こうと手助けしてくれ、自分は起業することができ働くことができましたが
僕みたいな精神障害をかかえ悩んでいる方が友達にもたくさんおり、どうにか自分たちの力で手助けができないかなと考えていたところ、パソコン特化型の就労継続支援b型を思いつきオープンすることになりました。
まだまだ日本の福祉業界は変化しなければいけないところが多く、地元一宮から全国100事業所を運営し、福祉業界に新たな旋風を起こしていきます！！！
