# 福岡・九州を若者の力で盛り上げたい！やる気のある学生たちの熱意の拠点となるシェアハウスを作りたい！

**更新日:** 2024.12.23

## 可知敬斗

21歳、大学生。地域活性に興味があり東京から九州・天草に移住。約3年間街づくりに取り組む。大好きな九州を盛り上げるため熱意ある若者の活躍する場を作り「若者の平熱を上げていきたい」

## やりたいこと

福岡を起点に九州全体を若者の力で盛り上げたい！空き家や遊休不動産を活用した若者向けシェアハウスを開き、熱意ある学生や若者を集め、何かが起こる起点の場として、色々なコトを興していきたいです。

## やりたい理由

本当はやる気・熱意があるはずなのに、行動までは移せていない若者/学生が九州に多いなと感じています。
このシェアハウスをきっかけに、若い人たちの熱量を膨らませ、表現できる場を作れたらと思いました。

## 希望物件の基本情報

エリア：福岡県福岡市、北九州市
(学生が多いエリア、もしくは色々な大学にアクセスの良い場所。特に、福岡市：早良区、城南区、東区 ／北九州市：小倉、八幡西区 など)
物件の広さ：50平米以上
希望賃貸価格：15万円以下
その他：学生がメインとなるため、電車でのアクセスが可能な場所
