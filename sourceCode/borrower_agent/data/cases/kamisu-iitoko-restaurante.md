# 茨城県神栖市で、地元の人々や訪れる人々が料理を通じて街と自分自身の豊かさに気づける飲食店を作りたい

## 酒井隼人

神栖市で生まれ育ち、洋食やイタリアンなど料理歴8年。料理人として生産者さんとお客さんの間をつなぎ、伝える人になりたいと、全国各地の農家や漁師さんを訪ねて食材について学んでいるところです。

## やりたいこと

料理を通して地域の魅力を発信して、人が訪れ交流できる場所を作りたいです。地元の茨城県神栖市で多種多様な人が集まり、自分自身や町の豊かさに気付ける飲食店を作りたいです。

## やりたい理由

安定した仕事が1番と思っていたこともありましたが、たくさんの人との出会いの中で豊かさは人それぞれで価値観はたくさんあることを知りました。
そんな素敵な場所を自分も作りたいと思いました。
