# 10年後「東美濃のインバウンド観光の隆盛はあの小さなホテルから始まった」と語られる、珠玉のHOTELを創りたい

## 船戸 正直

多治見で生まれ育ちました。
数年間名古屋と東京にて企業で働き、インターネットの可能性に賭けてUターンし起業。
以来25年近く、地方発のベンチャー企業として、新しい事業の創出と成長に挑戦し続けています。

## やりたいこと

「東美濃の旅の拠点」となる小さなHOTELを創りたい。 日本文化と東美濃の地域特性を織り込んだデザインの洗練された客室で、長期旅行をしている彼らが心からリラックスできる空間を提供します。

## やりたい理由

少子超高齢化が進む中で、地方の若者が故郷を見限り都市部へ移住し続ける・・・。
日本社会が抱えているこの重い問題を解決するカギが、地方観光業の隆盛だと考えています。

エリア：岐阜県多治見駅から徒歩5分以内
物件種類：一軒家、古民家、旅館、ビル、商店街、店舗兼住居
