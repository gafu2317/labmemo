# つらつらと過ぎる日常の中で、一旦立ち停まって考える場所を提供したい。

**氏名:** 塚原明日子  
**更新日:** 2025.05.27

## 塚原明日子

豊田市出身。大学卒業後、書籍編集に従事し、古美術の魅力に触れ骨董店に転職。その後、東日本大震災を機に豊田に帰郷し、息子の就職を機にコーヒー屋開業に挑戦中。

## やりたいこと

誰にも気を使わずゆっくり過ごせる静かな喫茶店を開きたいです。古い物や若手作家の作品も展示・販売し、物の価値を再認識する場にし、哲学カフェで様々な考えを共有できる空間を目指します。

## やりたい理由

子供時代、戦争の体験者から「みんなと同じ」を警戒する大切さを学び、同調圧力に抵抗しました。骨董や美術品を通じて物に込められた思いを感じ、社会で自分の選択を大切にする人を増やすべく、豊田で考える空間を作りたいと考えました
