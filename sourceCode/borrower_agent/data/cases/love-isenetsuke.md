# 「伊勢根付のアンテナショップ」と「材料の朝熊ツゲを育てる山」を作り、伊勢根付を産業化したい！

## 田中彩音

伊勢根付の現役職人である中川忠峰師匠に弟子入りするため、大阪から伊勢へ移住しました。
師匠の愛する伊勢根付、想いまでしっかりと受け継いだ職人になり、職人同士やお客さんを繋いでいくことが目標です。

## やりたいこと

①伊勢根付の魅力を伝えるアンテナショップを作ること
②朝熊山麓でツゲを育てること。山を管理することで伊勢根付の商売としての基盤を作り、職人たちが食べてゆけるように産業化を目指す

## やりたい理由

職人さんみんなと協力しながら、「伊勢根付文化」を継承・発展させるミッションに、これからの一生をかけて向き合っていきたい。
