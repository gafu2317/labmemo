# 和風なシーシャ屋を京都に作りたい

**氏名:** 平田 慎之助  
**更新日:** 2022.02.16  
**URL:** https://sakasama-fudosan.com/lessee/wahuu-si-sya-kyoto/

## 平田 慎之助

シーシャ屋〇〇代表　平田慎之助と申します。２０００年生まれの奈良県出身です。
高校卒業後1年間浪人を経て、現在同志社大学商学部２回生休学中です。
２０２０年夏　シーシャの世界を初めて知る
２０２０年秋　スマホのSIM代理店での営業をするようになる
２０２１年春　シェアハウス「照らすハウス」創設
２０２１年夏　シーシャを学ぶためにシーシャ屋で働き出す
２０２１年冬　大阪で新店シーシャBAR立ち上げに携わり、メニュー開発、人材育成、オペレーション作成などを行う

## やりたいこと

京都らしい和風で風情のある空間で、シーシャを楽しめてゆったりと過ごしてもらえる空間を作りたくて、日常を忘れられる空間にしたいなと思っています。
スポーツや運転に人柄が出ると言われるように、シーシャの味にも人柄が出ると思っていますので、
フレーバーの味と一緒に自分たちという人間や、自分たちが作り出す空間を感じて楽しんでいただきたいと思っています。

## やりたい理由

最初はただ好きでシーシャを自分のために作って吸っていました。
しかしある日シェアハウスでたまたま友人にシーシャを振る舞う機会があって、
その時に、「今まで吸った中で一番ウマい」と言われたことが嬉しかったのをきっかけに、他人に振る舞うためのシーシャを学びたいと思い始めました。
そしてそういった出来事を継続した結果、どんどんファンが増え店舗化してより多くの人たちへ、より１００％作り込んだ空間でチルを届けたいと思うようになり現在へ至ります。
