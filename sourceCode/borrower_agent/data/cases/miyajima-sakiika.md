# その場で焼いて実演することで、新食感が味わえる「鳥居さきイカ」を店舗として復活させたい！

## 浜田真紀

広島県出身。主人と共にステンドグラスの受注生産から建築業を経験。さらに食品販売へと事業を展開し、コロナ前までスーパーや宮島口のターミナルなどで「鳥居さきイカ」を20年以上販売していました。

## やりたいこと

宮島口に店舗を構え、「鳥居さきイカ」を製造・実演販売していきたいです。プロの焼き手が焼いたものを、さきイカをさく機械でさいていき、よく喋るおばちゃん(私)が袋つめをしていきます。

## やりたい理由

コロナで休業後、様々なお客様から「次いつやる？」などの声をいただきました。お店にフラッとくる地元の方が、「最近どう？」と声をかけてくれるような地域のハブとなれるような存在になりたいと思っています。
