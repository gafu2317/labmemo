# 子供が満たされる活動の場を作りたい

**掲載者:** FUNRISE代表  
**氏名:** 守屋 春輝  
**更新日:** 2021.12.20  
**URL:** https://sakasama-fudosan.com/lessee/kodomo-katsudounoba/

---

## 守屋 春輝

守屋春輝と申します。
FUNRISEという団体の代表をしております。
大学では教育学部を卒業、そこから小学校の先生を1年半ほどやっておりました。
その中で、学校教育だけでなく家庭にいる子供も支えたいと思い始め社会福祉士の資格を取得しました。
現在はその資格を活かし、ソーシャルワーカーとして病院で活動しております。

## やりたいこと

学校と家庭。
二つの子供の環境を考えた時にもっと子供が満たされる場所を作るにはどうしたらいいのか？考え、
子供たちが安心安全を感じ、大人が適切に関わり、子供が達成感を感じることができるようなフリースペースを作りたいと思うようになりました。
そんな中で特にやりたいことは
①「学校に行きたくないな」と思っている子供がふらっと遊びに来れるような場所にすること
②勉強のための場所じゃなくて自主活動の場所にすること
③経済的に豊かではない子供でも勉強できるような場所にすること
この３つが実現できる場所にしたいと考えています。
