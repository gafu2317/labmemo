# 士業(弁護士、税理士、司法書士等)が集い、誰でも気楽に悩み解決ができる「Samurai Cafe(サムライカフェ)」がやりたい！

**更新日:** 2024.02.22

## 石井 久美子

昭和49年、三島生まれ。理容学校を経て東京で劇団やモデル活動。父親の言葉がきっかけで30歳を過ぎてから社会保険労務士に転身。現在、「会社のお医者さん」として人や企業の環境整備に情熱を注いでいます。

## やりたいこと

仕事や経営の悩みからプライベートの悩みまで何でも相談できるカフェ。
士業（弁護士、税理士、司法書士等）が集結し、誰でも気楽に安心して相談できるそんな場所を作りたいです。

## やりたい理由

社労士として感じる士業へのハードル。誰もが悩みを抱え相談が難しい現実。このカフェが心を開ける場となり、情報や繋がりが広がり人生のキッカケになって欲しい。そんな心地よいカフェをやってみたいと思いました。

## 希望物件の基本情報

エリア：静岡県三島市（熱海市、長泉町、清水町、沼津市、静岡市も検討）
希望賃貸価格：5万円以下
広さ：50平米前後
その他：駐車場2台くらい近くに停められる／街中(オフィス街)／カウンターがあるとうれしい

### 物件を探している地域
