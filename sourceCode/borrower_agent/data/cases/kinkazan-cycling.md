# 金華山の麓で自転車屋をやりながら、地域を活性したい

**氏名:** 井田　実  
**更新日:** 2024.07.10

---

## 井田　実

生まれも育ちも岐阜市の自転車好きです。実現に向けた第一歩として、この春に勤めていた会社を退職し、長野県松本市の自転車メンテナンスの専門学校卒業後にUターンし開業したいと考えています。

## やりたいこと

自転車店の開業をきっかけに、ママチャリ・ロードバイクを問わず全ての自転車を対象としたイベントを開催することです。地域の飲食店・宿泊業との連携を中心に継続的な地域活性化に繋がるようにしていきたいです。

## やりたい理由

夢は生まれ育った岐阜市に恩返しすることです。大好きな岐阜がこれからの長い年月を永続的に皆が助け合いながらも、個々が幸せを感じられる地域にしたい、その実現に向けて地域のお役に立てればと考えています。

## 希望物件の基本情報

エリア：岐阜県岐阜市　金華山の麓周辺
物件の広さ：40平米以上

その他：音出し（自転車店のエアコンプレッサーの音、生音ライブ演奏年一回）OK、駐車場は最低2台
