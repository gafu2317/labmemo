# 人を幸せにするおにぎりやさん！

**氏名:** 橋本将護  
**更新日:** 2021.02.09  
**URL:** https://sakasama-fudosan.com/lessee/siawase-onigiri/

---

## 橋本将護

名古屋のかさでらにて間借りキッチンでおにぎり屋をやってます！！
2020年の12月からはじめました。
はじめた経緯としましては、間借りの場所を探していたときにあんまりピンとくる物件がなくて困っていたところ、ひょんなところから笠寺の物件に行き着きそこで新しい挑戦をすることにしました。
今まで飲食店で働いていたり、居酒屋だったり焼き鳥屋さん、バーなどで働いていたのでいつか自分でお店出したいという想いがありました。
そこで一番親しみやすそうなおにぎり屋さんをやろうと思いました。
お店では 具材の味付けだったり 普段のおにぎり屋さんにないようなメニュー色々飲食店をやってきて物件があれば店をひらきたいと思ってます！

## やりたいこと

食で人を幸せにしたいと考えています。
僕は４人兄弟で、一番したの子とは12歳離れているのですが小さい頃に弟たちにご飯を作ってあげて喜んでくれた経験が今の僕に繋がっていると考えています。
なので僕は、僕が作ったご飯を食べて幸せになってくれるようなお店を作りたいと思っています。ただ食意外にも興味もあるので音楽ライブなども開催できたら嬉しいです。
