# 東濃の魅力を発信するスタジオ兼シェアハウスを作りたい

**更新日:** 2020.05.19

## 笛吹侑暉

映像を作っている仕事をしています。
主に、イベントのアフタームービーや観光PR系の動画を制作しています。
人が喜んでいる表情のシーンや、街の風景、魅力を動画を通して人に伝えるのが得意です。
フリーで動画制作を始めて2年目で、それまでは会社員として働いていました。 瑞浪市の観光協会に載っている動画も作りました。
自分が欲しいものは自分で作るということが好きなので、いろりを作ったり、ピザ窯を造ったりしたいと考えています。
また自然が好きなので、キャンプに行くのが好きです。 イベントに関わっているのがアウトドアの会社なのでそのご縁でアウトドア環境に触れることも多いので全国のキャンプエリアを回ることもあります。
プライベートでは恵那の保古の湖キャンプ場によくいきます。

## やりたいこと

地元の友達５、６人でシェアハウスをやりつつ、自分の仕事で活用できるようなスタジオも持てる家に住めたらと考えています。
そこで東濃の魅力を自分の得意な映像制作などを通して伝えていけたらと考えています。
自分がDIYできるのでいろりを作ったり、ピザ窯を作ったりもしたいです。
そういったことをしながら人と集めてイベントをしたりとも考えています。
近隣の人とは仲良くしたいと考えていますが、大きな音やたくさんの人が出入りする可能性があるのでそういったことに理解がある地域の物件だと嬉しいです。
瑞浪のかまどエリアは地元なので、そこ以外だと嬉しいです。

## やりたい理由

東濃が好きで、生まれてこの方東濃にずっと住んでいるのので東濃の魅力を発信していきたいと思っています。
