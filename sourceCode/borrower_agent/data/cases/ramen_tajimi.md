# 多治見でカルチャーミックスな新しいラーメン店を開業したい

**氏名:** 小野田 生(しょう) / 吉田 圭佑  
**更新日:** 2023.03.14  
**URL:** https://sakasama-fudosan.com/lessee/ramen_tajimi/

---

## 小野田 生(しょう) / 吉田 圭佑

僕（小野田さん）は多治見のカルチャーを取り込んだ面白いことを発信する一味違ったラーメン屋を作っていきます。私（吉田さん）は私の得意な分野で彼とタッグを組んで盛り上げていけたらと思います。

## やりたいこと

おもしろい街・多治見でラーメン屋をやりたいと思っています。
店を訪れたお客さんが「美味しい・おもしろい・楽しい」と思ってもらえるような、ラーメン屋っぽくないラーメン屋を目指します。

## やりたい理由

僕は、愛知県豊田市のごはん屋カカという定食屋を兄弟で経営しています。普段から多治見へ足を運ぶことが多く、魅力的なお店が多いこの街で自分もラーメン店を始めたいと思いました。

## 希望物件の基本情報

エリア：多治見市内
広さ：18坪～20坪
物件種類：古民家、一軒家
理想賃貸金額：10万円前後
その他の条件：カウンターあり（８名くらい）、家族づれも来られるように小上がりを作って、テーブル席も。
飲食に理解がある大家さん、 内装なども自由にさせてもらえる、 一番奥まで中を見渡せる物件が理想です。

### 物件を探している地域

- **岐阜県:** 多治見市
