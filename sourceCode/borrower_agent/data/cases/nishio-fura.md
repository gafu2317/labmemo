# フラを通して「心と身体の健康」を与えるパワースポットとなる場所をつくりたい

**氏名:** 有馬　恵美代  
**更新日:** 2024.02.11  
**URL:** https://sakasama-fudosan.com/lessee/nishio-fura/

---

## 有馬　恵美代

西尾市一色町在住。市内を拠点に活動するフラダンス教室の代表をしています。ハワイの先生より指導を受け、市内ふれあいセンターにて、4歳〜80代までの生徒さんたちの指導にあたり、楽しくフラを学んでいます。

## やりたいこと

時間を気にすることなく、いつでも、フラの練習や、ハワイ・フラの楽しさを共有できるスタジオを作りたい。みんなで、レイや衣装を作ったり、技術的な向上をめざすために鏡のある部屋で練習したい。

## やりたい理由

フラ・ハワイについて学ぶ場所を作ることで、そこに集まってくださった皆さんの生活に潤いを与えられたらと思います。
